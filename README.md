# AskJamie Concierge

Find a useful AI agent skill, understand what it does, and put it to work with clear guidance.

AskJamie Concierge matches a description of your task to a small, reviewed catalog of business skills. Each recommendation explains the expected result and how to use the skill with your chosen agent.

## Foundation

This workspace is being built in ten reviewable steps. The first release covers discovery, guided application, and catalog governance. Self-service contribution interviews, enterprise deployment, and billing are outside this release.

See [architecture](docs/architecture.md), [brand voice](docs/brand-voice.md), and [agent instructions](AGENTS.md).

## Development

Node.js 24 and pnpm 10 are required. Install dependencies with `pnpm install`.
