# AskJamie development skills

These seven project-local skills support Replit development, design, task
handoff, and repository maintenance. They are development tooling only. They
are not public catalog entries and receive no trust status or publication
approval from being installed in this folder. The public catalog's mechanical
checks and content-bound judgment requirements still apply to any admission.

Active skill names use `askjamie-replit-*`. Run documented repository-relative
commands from the Git root, using coordinates discovered from the current
remote. On Windows, use `py -3` where `python3` is unavailable.

Imported evaluation and benchmark records are historical upstream evidence,
not current validation of these renamed and modified packages. Preserve their
original names, paths, quotations, hashes, and results. Historical paths are
not local execution instructions. Record new validation against the actual
adapted revision and keep new telemetry output separate from imported records.

Original authorship and the MIT license are retained in
[the provenance notice](../../docs/licenses/replit-skills-provenance.md).
