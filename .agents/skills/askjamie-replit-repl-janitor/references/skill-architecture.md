# Skill architecture

Audit and tidy one Replit workspace's Git checkout, distinguish hosted pull
request evidence from local Git facts, and preserve uncertain work.

Scope includes branch classification, naming and detritus audits, exact cleanup
plans, and execution within the owner's authorization. It excludes scheduled
maintenance, unrelated repositories, restructuring, and history rewriting.

The package uses the AskJamie identity. Original authorship and MIT licensing
remain in [the provenance notice](../../../../docs/licenses/replit-skills-provenance.md).
Historical imported evaluations do not certify the adapted package.
