# Interface design

The implementation uses a text-only AskJamie wordmark, white background, forest teal (#17594f), charcoal text (#243531), muted gray (#65746f), pale sage (#f3f7f5), and fine gray-green borders. Use system sans typography, a responsive 44px main heading, 17–19px introduction, and deliberately sized form controls.

The primary screen places a goal form beside a three-step guidance rail. Mobile stacks the rail below the form. The native select is closed initially; an open option menu in the design reference illustrates available choices. Results continue in the same conversation region with the person's goal, a ranked recommendation, trust sentence, and next action. No taxonomy or raw scanner scores are shown.

The review desk uses an open queue-and-detail layout with the same tokens. Approve/reject controls follow the package and rationale fields. Empty and failure states remain explicit. Screenshots are design and QA working artifacts outside repository source; the product itself is native HTML, CSS, and React.
