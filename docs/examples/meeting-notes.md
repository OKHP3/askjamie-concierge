# A task you can describe to the concierge

“I have rough meeting notes and need a summary with decisions, owners, and next steps.”

Choose your supported agent when prompted. Read the recommendation, add the skill using the platform guidance, and try it on a short set of notes you are permitted to share.

A useful check: if the notes omit an owner or date, the result should say “Not specified,” not invent one. Review the result before sharing it. After trying the skill, record whether it helped using the concierge's feedback controls.
