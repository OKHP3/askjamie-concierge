# Brand and writing

Use AskJamie Concierge as the product name. Write as a competent professional helping a colleague: calm, precise, reassuring, and direct. Explain what a person can do next without requiring them to understand implementation details.

Use original, business-appropriate examples. Avoid unrelated personal brands, family names, internal codenames, contentious opinions, profanity, humor at a user's expense, and exaggerated promises.

Say “Reviewed for this catalog,” not “Guaranteed safe.” Say “I could not find a good fit,” then explain a useful next step. Do not expose scores or technical governance vocabulary in public recommendations.

Repository source, comments, filenames, branch names, workflow names, and commit messages use product-specific or neutral terminology. Never embed an account name or machine-specific path in source. External hosting metadata is managed by the hosting provider.
